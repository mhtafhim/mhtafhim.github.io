# Mahmudul Haque — portfolio

Simple static portfolio for recruiters, served by GitHub Pages. No package installation or build step is required.

## Editing

- `index.html`: primary content, experience, selected projects, education, and contact.
- `assets/css/portfolio.css`: responsive layout and visual styles.
- `about.html` and `projects.html`: preserve existing URLs by forwarding to the corresponding homepage sections.
- `blog.html`, `post.html`, and their existing assets are retained as the writing archive.
- `data/profile.json`: legacy profile data; the homepage is rendered directly in HTML so essential content is available without JavaScript.

Use confirmed information from the sibling resume repository's `PERSONAL_BACKGROUND.md` and general CV sources. Keep planned relocation distinct from current residence, university projects distinct from employment, and no personal phone number in the public profile. Review October 2026 study and availability details when those plans change.

Preview with any local static HTTP server. Check desktop and mobile widths and keyboard navigation before publishing. Changes go live through the repository's existing GitHub Pages configuration after they are pushed; editing local files alone does not publish them.
