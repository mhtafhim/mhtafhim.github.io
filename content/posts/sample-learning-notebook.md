There is a difference between encountering an idea and understanding it well enough to use it. A small learning notebook can help bridge that gap. It does not need to be polished or comprehensive; it only needs to make a useful thought easier to find again.

## Start with a question

A question gives a note a reason to exist. Instead of collecting everything about a topic, start with something specific: Why did this approach fail? What does this term mean in practice? What would I try differently next time?

The answer can remain incomplete. A note that clearly states what is still confusing is often more useful than a confident summary copied from somewhere else.

## Keep the format simple

Three short prompts are enough:

- **Question:** What am I trying to understand?
- **Experiment:** What did I try or read?
- **Takeaway:** What changed in my understanding?

### Save the context

A link, a small code snippet, or a sentence about the situation can make an old note understandable months later. The goal is not to document every detail, but to leave enough context to resume thinking.

## Revisit rather than collect

An occasional review can reveal repeated questions and connections between topics. Some notes will turn into practical references. Others may become the beginning of a blog post or a short video explanation.

## A useful place to begin

Choose one question from today and write five sentences about it. There is no need to build an elaborate system before starting. The useful part is the thinking, not the tool.
